# Project AI Entry Point

This repository is managed with the Portable Project Context Specification from ChatGPT Development OS.

Canonical repository: `zzpsah/Browser-Chrome-Automation`.

Before substantial work:
1. Read `.ai/manifest.yaml` and `.ai/STATE-INDEX.md`.
2. Read `.ai/PROJECT.md` and `.ai/CURRENT-STATE.md`.
3. Read decisions/tasks/architecture.
4. Inspect current source and Git history before implementing browser automation.

User login, OTP, CAPTCHA, and authorization boundaries must remain user-controlled unless explicitly authorized otherwise. Never store credentials, cookies, or tokens in `.ai/`.

`.ai/STATE-INDEX.md` is generated by Development OS automation and should not be manually edited.
